# cnation-video-loop
from image to video loop generator app @cnation

## 홈 화면에 추가 (PWA)

HTTPS 정적 호스팅(GitHub Pages, Vercel 등)에 올린 뒤 Safari 또는 Chrome의 공유 메뉴에서 '홈 화면에 추가'를 누르면 앱 아이콘으로 실행됩니다.

- index.html: 앱 본체
- manifest.json: 앱 이름·색상·아이콘 정보
- icon-192.png, icon-512.png, apple-touch-icon.png: 홈 화면 아이콘
